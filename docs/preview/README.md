# Локальные контрольные кадры

Эти кадры сняты из локальной production-сборки `/compute/` при размере окна 1280 × 800 и 360 × 800. Они показывают начало, середину и завершение передачи данных на шагах 2, 3, 4, 8, 9 и 10. `addition-walkthrough.webm` фиксирует проход вперёд и возврат с шага 10 до шага 8. Это материалы для проверки, а не опубликованная версия сайта.

Для повторной съёмки запустите локальный preview на `http://127.0.0.1:4321`, затем выполните `node scripts/capture-compute.mjs`. Скрипт перезапишет только файлы этих контрольных кадров в данной папке.
