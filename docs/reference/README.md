# Утверждённые ключевые кадры

Эти три изображения экспортированы из предоставленного пользователем файла `Архитектура процессора ключевые кадры сцены.html` (1280 × 760). Они задают композицию и визуальный язык, но не заменяют [утверждённую спецификацию](../superpowers/specs/2026-10-10-addition-simulation-design.md): подписи, нумерация и детали исходных макетов могут отличаться от финального девятишагового сценария.

- `keyframe-1-input.png` — макроплан и ввод.
- `keyframe-2-registers.png` — путь к регистрам.
- `keyframe-3-alu.png` — крупный план ALU и таблица сложения.

Скриншоты этапов 4а–4в сравниваются с этими файлами по композиции, типографике, контрасту и расположению активных элементов. Объёмная геометрия дорабатывается по спецификации.
