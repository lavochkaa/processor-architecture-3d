# Утверждённые ключевые кадры

Эти три изображения экспортированы из предоставленного пользователем файла `Архитектура процессора ключевые кадры сцены.html` (1280 × 760). Они задают композицию и визуальный язык, но не заменяют [актуальную спецификацию](../superpowers/specs/2026-10-11-computer-data-path-redesign.md): подписи, нумерация и детали исходных макетов могут отличаться от финального десятишагового сценария.

- `keyframe-1-input.png` — макроплан и ввод.
- `keyframe-2-registers.png` — путь к регистрам.
- `keyframe-3-alu.png` — крупный план ALU и таблица сложения.

Скриншоты этапов 4а–4в сравниваются с этими файлами по композиции, типографике, контрасту и расположению активных элементов. Объёмная геометрия дорабатывается по спецификации.

Локальные результаты прежней версии: `4a-static-board.png`, `4b-step3.png`–`4b-step8.png`, `4c-step4.png`–`4c-step8.png`, `4g-mobile-alu.png`, `4g-fallback.png` и [финальный экран на шаге 9](5-step9-result.png). [Замер производительности](4g-performance.md) и [сверка источников](2026-10-10-source-check.md) фиксируют условия проверок.
