# Проверка устойчивости 3D-сцены

Дата: 10 октября 2026. Локальный Chromium (headless), production-сборка, эмуляция CPU ×4 через DevTools; это не измерение слабого мобильного GPU.

- Переход к шагу 4 на 1440 CSS px: 107 мс до обновления счётчика, 110 мс до видимого canvas.
- Переход к шагу 4 на 390 CSS px: 103 мс до обновления счётчика; горизонтальное переполнение — 0 px. [Кадр](4g-mobile-alu.png) показывает, что таблица не закрывает активный FA0.
- После завершения перехода число WebGL draw calls не выросло за следующие 900 мс (7105 → 7105). Автоматический тест также проверяет остановку рендера по требованию.
- Потеря контекста через `WEBGL_lose_context.loseContext()` сохраняет шаг 4 и таблицу, переключая сцену на [плоский маршрут](4g-fallback.png). Отдельный запуск Chromium без WebGL проверяет тот же запасной режим.
- При `prefers-reduced-motion: reduce` пользователь по-прежнему может вручную перейти к ALU, но движение камеры и сигналов завершается сразу.

Эта проверка подтверждает отзывчивость в эмуляции CPU; перед публичной выкладкой полезно дополнительно посмотреть плавность на реальном телефоне.
