# Архитектура процессора

Образовательный сайт об одном маршруте: физическое нажатие клавиши A на проводной USB HID-клавиатуре → строчная `a` в активном поле браузера.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run test:a11y
npm run build
npm run test:budget
```

Для браузерных проверок при первом запуске установите Chromium: `npx playwright install chromium`.

## Границы кода

- `src/content/scenarios/`: типизированный и проверяемый при сборке учебный сценарий, источники и вопросы.
- `src/domain/scenario-engine/`: переходы состояния без зависимости от 3D.
- `src/domain/capabilities/`: проверка WebGL и переход к 2D.
- `src/components/`: доступный интерфейс, единый для всех режимов.
- `src/renderers/scene-2d/` и `scene-3d/`: только визуальные адаптеры.
- `src/pages/`: статические страницы и текстовый маршрут без JavaScript.

3D-чанк загружается после выбора режима. Базовый маршрут доступен как HTML ещё до загрузки 3D. Браузерный сценарий не записывает реальные нажатия и не отправляет аналитику.

Сборка использует `SITE_URL` для canonical URL и sitemap; по умолчанию задан адрес проекта Sites. Порог `test:budget` ограничивает gzip-объём начального JS, отложенного 3D и CSS. Порог не заменяет измерение времени до интерактивности на целевом устройстве.

Учебная модель ограничена указанным профилем. Точные механизмы ОС, браузера и дисплея могут различаться. Перед широким образовательным использованием желательна независимая техническая рецензия.
