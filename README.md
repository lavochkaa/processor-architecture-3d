# Архитектура процессора

Образовательный сайт о двух учебных маршрутах:

- `/scenario/` — физическое нажатие клавиши A на проводной USB HID-клавиатуре → строчная `a` в активном поле браузера;
- `/compute/` — два числа от 0 до 15 → четыре разряда сложения с переносами → пятибитный ответ.

Сложение проходит девять шагов из одной проверенной трассы. Арифметика проверена на всех 256 парах операндов. Процедурная 3D-сцена, доступный плоский маршрут и переход при потере WebGL готовы для локального превью; существующий публичный сайт до отдельного подтверждения не обновляется. [Спецификация](docs/superpowers/specs/2026-10-10-addition-simulation-design.md), [план](docs/superpowers/plans/2026-10-10-addition-simulation-plan.md) и [визуальные ориентиры](docs/reference/README.md) открыты для просмотра.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run test:a11y
npm run build
npm run test:budget
```

Для браузерных проверок при первом запуске установите Chromium: `npx playwright install chromium`.

## Границы кода

- `src/content/scenarios/`: типизированный и проверяемый при сборке учебный сценарий, источники и вопросы.
- `src/domain/scenario-engine/`: переходы состояния без зависимости от 3D.
- `src/domain/capabilities/`: проверка WebGL и переход к 2D.
- `src/domain/arithmetic/`: чистая арифметика, девять состояний и контроллер навигации.
- `src/components/`: доступный интерфейс, единый для всех режимов.
- `src/renderers/scene-2d/`, `scene-3d/` и `arithmetic-3d/`: только визуальные адаптеры.
- `src/pages/`: статические страницы и текстовый маршрут без JavaScript.

3D-чанк сложения загружается только после запуска вычисления при доступном WebGL. При его отсутствии или потере тот же шаг остаётся в плоском маршруте. Текстовый разбор примера доступен как HTML без JavaScript. Браузерный сценарий не записывает реальные нажатия и не отправляет аналитику.

Сборка использует `SITE_URL` для canonical URL и sitemap; по умолчанию задан адрес проекта Sites. Порог `test:budget` ограничивает gzip-объём начального JS, отложенного 3D и CSS. Порог не заменяет измерение времени до интерактивности на целевом устройстве.

Учебная модель ограничена указанным профилем. Точные механизмы ОС, браузера и дисплея могут различаться. Перед широким образовательным использованием желательна независимая техническая рецензия.
